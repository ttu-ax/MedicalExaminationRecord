# 体检记录 Android App

首版功能：多张图片导入与拍照、Qwen3.7-Flash 报告识别、逐项校对、本地报告库、指标折线图、阶段标记。报告确认后才进入趋势；每次检测的原始参考范围会保留。

## 运行

1. 安装 JDK 17+、Android SDK（API 35）及 Android Studio。用 Android Studio 打开项目，或运行 `./gradlew assembleDebug`，安装 `app/build/outputs/apk/debug/app-debug.apk`。
2. 在 App 的“设置”中填写百炼 API Key。北京地域业务空间和模型已内置；Key 由 Android Keystore 加密保存在本机，不写入 APK。
3. 从首页选择图片或拍照。识别时在弹窗中显示逐张进度、当前步骤和自动滚动的模型实时输出；识别完成后关闭弹窗，进入第一份报告校对页。
4. 核对采样日期、数值、单位与参考范围，点击底部“确认报告，加入趋势”。一次导入多份时会继续打开下一份待校对报告。首页和报告页都能继续处理待校对项。

应用启动时会自动通过 Gitee Release 检查更新；也可在“设置”中查看当前版本并点击“检查更新”。设置页会显示最新版本、检查失败原因，或弹出可下载安装的新版本。下载后会校验 APK 的 SHA-256。

发布新版到 Gitee：按 [发布说明](server-site/README.md) 配置签名与令牌，然后运行 `scripts/publish-gitee.cmd`。该入口不连接自托管网站。

底部导航为首页、报告、阶段三项。进入报告分类后，可在“报告｜趋势”之间切换；选定指标后汇总各分类中的同名已确认记录，按采样日期绘制一条折线。同名指标按相同单位处理；点按数据点查看原报告中的单位、来源分类与结果。设置从首页进入。详情与设置页支持 Android 返回手势及系统返回键。

## 报告分类与校对

- 识图模型先给出报告类型（血常规、生化、凝血或其他）；不确定时可由决策模型辅助判断。若最终仍为“其他”，识图模型的建议分类名会保存在报告中，校对页可一键创建分类并移入报告。类型保留在报告信息中。
- 每份报告另有可修改的“分类”。新报告默认使用识别出的类型；旧报告升级后沿用原类型作为初始分类。报告页先显示分类，再进入分类内的报告列表。用户可新建、重命名分类，在报告详情中移动报告，并删除空分类。
- 校对页上方固定显示原始报告图片，可双指缩放、拖动、旋转和复位；下方指标列表独立滚动，点击项目会在列表内展开编辑，原图保持可见。采样日期、报告日期与阶段起止日期均使用日期选择器。
- 阶段页改为月视图：点开始和结束日期后填写类型、名称与措施；“持续至今”可不选结束日期。阶段以跨日期的半透明色条叠加在日历上，点击色条可编辑；删除前再次确认。

App 通过 HTTPS 直接连接百炼，手机不需要连接电脑，也不需要启动 `server/server.py`。电脑端的 `.env` 可用于开发样例验证和 Gitee 发布；如需验证本地服务，可在项目根目录创建 `.env`：

   ```env
   APIKEY=你的百炼API Key
   BAILIAN_WORKSPACE_ID=你的北京地域业务空间ID
   # 仅当本机代理导致百炼连接失败时使用
   BAILIAN_NO_PROXY=1
   ```

运行 `python server/server.py` 可单独验证本地服务，但 App 不会调用该服务。`10.0.2.2` 仅适用于 Android 模拟器，实体手机无法用它访问电脑。

## 模型流程

- Qwen3.7-Flash 通过百炼 Chat Completions 接口流式读取图片，返回 JSON Object。App 校验字段，保留原文，不填造缺失参考范围。
- 当 Qwen 返回“其他”类型时，决策模型根据项目名称给出类型建议；只有置信度达到 0.8 才采用建议，报告仍须用户校对。
- API Key 由用户在 App 设置页填写，使用设备密钥库加密保存；安卓 APK 不包含 Key。`.env` 已被 Git 忽略。

## 当前范围

已实现图片导入、拍照和手工项目录入。PDF、多设备同步、备份恢复和正式部署服务尚未接入。当前直连方案适合个人测试；面向其他用户发布时，应改由受控后端管理密钥与访问。

本项目用于个人记录。阶段与趋势可对照时间变化，不据此自动判断某项措施的效果。
